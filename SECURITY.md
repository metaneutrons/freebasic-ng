# Security policy

## Supported versions

Security fixes are made on the current `main` branch until the project publishes
its first stable release. Supported release lines will be listed here afterwards.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub private
vulnerability reporting for this repository. If that option is unavailable,
contact the repository owner privately through GitHub.

Please include a minimal reproducer, affected platform and compiler version.
We will acknowledge a report promptly and coordinate disclosure before a public
fix is published.
