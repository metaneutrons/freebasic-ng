# M5 — Repository tidy-up

This plan is the acceptance authority for M5. It governs the implementation
issues [#71](https://github.com/metaneutrons/freebasic-ng/issues/71) and
[#72](https://github.com/metaneutrons/freebasic-ng/issues/72), the M5
[milestone](https://github.com/metaneutrons/freebasic-ng/milestone/6), and the
M5 [epic](https://github.com/metaneutrons/freebasic-ng/issues/54). The
[legacy inventory](legacy-inventory.md) remains the catalogue of inherited
paths; it is not a second M5 acceptance checklist.

## Outcome and boundaries

M5 removes only legacy release machinery whose replacement has a measured,
current release-path equivalent. It makes the maintained target set explicit
without rewriting FreeBASIC history, relicensing upstream material, or deleting
unqualified source support opportunistically.

M5 does not remove the generated bootstrap sources, the root GNU make path,
historic documentation, installers, or manifests. Nor does it promote an
experimental target to supported status.

## Target decisions

| Status | Targets | Decision and required evidence |
| --- | --- | --- |
| Retain | Linux x86_64/aarch64, macOS x86_64/aarch64, Windows x86_64/aarch64 | These are the complete Tier 1 native host/release set. CMake CI builds, stages, and runs an independent program on each host; stable releases publish all six archives. |
| Retain as developer preview | AmigaOS 3/m68k | Retain its CMake target-SDK path. It has runtime-marker and independent FS-UAE process-exit evidence, but is not a Tier 1 host or public release target. |
| Port in M6 | AROS x86_64, ARM and AArch64; MorphOS PowerPC | AROS remains blocked on a stable `metaneutrons/aros-toolchains` release acquired through the `aros` CLI from `metaneutrons/aros-tools`, as recorded in [#103](https://github.com/metaneutrons/freebasic-ng/issues/103). MorphOS has a CMake runtime/link path but needs executable runtime evidence under [#104](https://github.com/metaneutrons/freebasic-ng/issues/104). Neither is released or supported before that evidence exists. |
| Retire from the maintained product surface | AmigaOS 4, DOS, Xbox, Android, Cygwin, JavaScript/Emscripten, FreeBSD, NetBSD, OpenBSD, DragonFly, Solaris, Linux x86/ARM32, macOS x86, Windows x86, and every other historical GNU-make-only host/architecture combination | No current CMake bootstrap, tested runtime, package channel, or release commitment exists for these variants. Their source stays unchanged as inherited history; this is a support and distribution decision, not a claim that the code is deleted. A future reintroduction requires a dedicated CMake toolchain, bootstrap/input provenance, CI runtime evidence, and an explicit plan revision. |

The root `makefile` is deliberately retained. Its `unit-tests`, `log-tests`,
warning/syntax checks, `gitdist`, and `bindist` capabilities have no equivalent
CMake test/package path. `FB_BUILD_TESTS` now owns focused Darwin ARM compiler
regressions, including the native self-host path, but does not yet execute the
full unit, log, warning, syntax or documentation suites. It also still consumes
`contrib/manifest/` and `contrib/unix-installer/`. GNU make may be removed only
after the retained CMake paths run an equivalent test suite and the retained
packaging capabilities have a qualified CMake replacement.

The six declared bootstrap directories remain versioned inputs. CMake validates
each required input against `bootstrap/provenance.json`; no M5 change reduces
that inventory. The historical root-level `bootstrap/fbc` executable is not an
input: it is an ignored local output of the retained GNU-make
`bootstrap-minimal` target and must be rebuilt for its host.

## Scoped removals

| ID | Path | Decision | Gate and durable evidence |
| --- | --- | --- | --- |
| M5-R1 | `contrib/deb/` | Remove | The release workflow natively builds, installs, signs and attests amd64/arm64 `.deb` files, then hands the verified release to the central APT archive. Its retired DEP-5 `copyright` record is preserved verbatim in [`docs/history/debian-packaging-copyright`](../history/debian-packaging-copyright). Stable [v1.22.3](https://github.com/metaneutrons/freebasic-ng/releases/tag/v1.22.3) and [run 34663111902](https://github.com/metaneutrons/freebasic-ng/actions/runs/34663111902) are the qualification evidence. |
| M5-R2 | `contrib/rpm/` | Remove | RPM is not a FreeBASIC-NG distribution channel. No maintained RPM replacement is promised; adding one needs a new planned, qualified channel. |
| M5-R3 | `contrib/release/` | Remove | The attested GitHub-release workflow replaces the old local assembler for every maintained deliverable. The historical manual page is retained and explicitly marked as superseded. |
| M5-K1 | `.travis.yml`, `contrib/travis/` | Keep | CTest owns the full historical unit suite on Darwin ARM and the historical log suite through a native Linux x64/GCC self-host, in addition to focused compiler regressions. The former 32/64-bit debug, GAS64, warning, syntax and documentation coverage remains absent, so GitHub Actions is not yet a proven replacement. |
| M5-K2 | `contrib/manifest/`, `contrib/nsis-installer/`, `contrib/unix-installer/` | Keep | The retained root make `bindist` target consumes the manifest and Unix installer. The modern package/archive path has clean-install tests, but no successful installer upgrade test. |
| M5-K3 | `bootstrap/`, `todo.txt`, `changelog.txt`, historic documentation | Keep | Bootstrap provenance and upstream history remain necessary. The outdated release manual is annotated, rather than erased. |

## Acceptance criteria

1. **M5-A — Target policy:** every historical target is covered by one row in
   the target-decision table, and no retired or M6 target is advertised as a
   Tier 1 release.
2. **M5-B — Safe removals:** M5-R1 through M5-R3 are absent from the tracked
   tree; the M5-R1 DEP-5 licensing and attribution record is preserved
   verbatim in `docs/history/debian-packaging-copyright`; active documentation
   points to the maintained release path.
3. **M5-C — Retained gates:** M5-K1 through M5-K3 remain in the tree with their
   unsatisfied gate stated above. A search confirms no removed path remains in
   an active build, workflow or current release guide.
4. **M5-D — Replacement proof:** the plan revision and issue evidence identify
   v1.22.3, its exact source commit, and successful release run
   `34663111902`; the replacement scope covers the exact Debian and GitHub
   release machinery removed here.
5. **M5-E — Verification:** the standard check, Homebrew credential-flow check,
   local CMake configure/build/staged-install smoke test, and affected GitHub
   CI run succeed for the M5 commit. The completion issue maps every criterion
   to those durable results.
